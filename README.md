# AI Study Assistant – Smart Learning Agent

## About the Project

AI Study Assistant is an AI-powered chatbot built using n8n and Google Gemini to help engineering students learn technical subjects.

## Features

* Explains Java, Python, SQL, DSA, AI, and web development.
* Provides step-by-step explanations in simple English.
* Generates viva questions and answers.
* Creates MCQs for exam preparation.
* Helps students understand programming errors.
* Explains code line by line.
* Performs mathematical calculations using a calculator tool.
* Maintains conversational context using memory.

## Technologies Used

* n8n
* Google Gemini
* AI Agent
* Simple Memory
* Calculator Tool

## Workflow

1. **Chat Trigger:** Receives the student's message.
2. **AI Agent:** Processes the question.
3. **Google Gemini:** Generates the response.
4. **Simple Memory:** Helps maintain conversational context.
5. **Calculator:** Supports mathematical calculations.

## How to Import

1. Download the workflow JSON file from this repository.
2. Open your n8n instance.
3. Import the JSON workflow.
4. Configure your own Google Gemini credentials.
5. Test the workflow before using it.

## Security

Never upload API keys, passwords, or private credentials to GitHub. Configure credentials securely inside n8n.
